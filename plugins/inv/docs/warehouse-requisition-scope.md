# 仓库申领范围

2026-11-10：仓库列表行内新增“申领范围”，使用独立权限 `inventory_warehouse:requisition_scope` 配置指定下级组织。管理端、小程序申领选项、物资查询和创建申请统一校验共享关系；不增加库存、成本、审批或发放权限。成员按当前主组织精确匹配，不自动继承到下级组织。

关系表为 `inv_warehouse_requisition_org`，撤销结束有效期并保留历史。新增申请来源组织及名称快照，历史不推断回填。配置保存校验仓库更新时间，提交与撤销使用同一仓库的共享/排他行锁。

按 inv 模型生成并审核目标租户的迁移，再同步权限。仓库管理员在「申领范围」配置可申领组织。
