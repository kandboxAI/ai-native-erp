# 统一位置接入

资产与仓库复用 inv 内部的位置模块，通过「位置信息」菜单统一维护。主设计及原环境升级记录见 [统一位置主设计](location-master-design.md)。资产原 ID、台账与交接历史保留，资产位置的公共字段为兼容投影；仓库原 location 文本作为补充说明保留。源码更新不代表数据库已升级或旧数据已清理。

资产位置独立菜单和「旧资产地点补关联」抽屉均已退役，原资产地点维护 HTTP 接口、手工补关联和改绑逻辑已移除。新资产直接选择统一位置，内部配置按需自动建立。责任部门在资产登记时必填，保管人可选；切换位置不覆盖已填写责任信息。正常登记、调拨和交接保留。

原多对一关联的存储、索引和引用保留，已有资产仍能按统一位置筛选。原有存储字段用于读取历史关联。历史入库补登记与核对同时退役，新收货通过确认入库自动登记，详见 [库存与资产闭环](inventory-asset-lifecycle.md)。
