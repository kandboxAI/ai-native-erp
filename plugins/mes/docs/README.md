# MES 设计文档

小程序「生产执行 → 扫码报工」打开后直接启动相机。扫描工单卡上的二维码后，按工单号查询当前账号可见的工序任务，点选工序即可进入报工。取消扫码后可再次扫码或手动查询。

销售管理支持询价、数量档报价、历史报价查询和客户订单。订单审核后可生成生产工单，订单详情可查看相关出货单和可出货工单。

新增出货单时，可按名称或编号从客户档案选择客户，再按需选择该客户的订单。从客户订单进入时直接带入客户和订单。工单来源按客户、订单和组织筛选，仓储出货只显示客户所属组织的仓库；保存时自动生成出货单号。工单未绑定客户时可按当前选中的客户登记出货。

工单关联客户订单时，选择货品会带入该订单明细的成交未税单价及原币种，单价不可在出货单修改，保存时由服务端读取并冻结。独立工单仍填写人民币含税单价。不同币种或计价口径须分别出货、对账。旧草稿可重新保存以带入订单价，已确认历史原样保留。

点击出货单列表的「查看」进入详情页，「单据」直接打开详情页的「出货单据」页签。该页签左侧填写出货资料及预览，右侧下载单据历史或登记正式发票；切换到「出货明细」核对货品时，保留本页已录入的出货资料。

出货单据使用本批出货明细生成 Excel。国内使用内置模板分别生成「发票」和「合同」。发票编号留空时使用出货单号，合同号留空时尝试带入本批唯一的客户采购单号。两份文件逐项带入货品、图号、数量、成交单价及本批金额，按币种和计价口径分别汇总。财务开具正式发票后，可登记号码、日期和 PDF。

出口生成三份 Excel。

| 文件 | 带入数据与录入来源 |
| --- | --- |
| 英文商业发票（INVOICE） | 每项带入客户采购单号、订单描述、图号、成交材料、币种和未税单价。本批金额按本次出货数量计算。收款说明由业务人员填写。 |
| 英文装箱单（PACKING LIST） | 保留订单逐项明细，使用实际箱号、箱内数量与净重、整箱毛重和尺寸。混装箱的毛重只计一次。 |
| 中文报关资料草稿 | 工作表按「报关单 附1」「装箱单」「发票」「合同」排列。报关单、发票和合同共用报关汇总，装箱单按箱展示该箱内各申报分组。 |

系统根据订单成交材料建议铝材料、钢材料或工程塑料。报关人员可调整类别或选择逐项申报。同类货品在申报品名、HS 编码、原产国、申报要素和计量单位一致时合并。组金额等于本批明细金额之和，汇总单价等于组金额除以数量，最多保留六位小数。分组总价始终使用明细金额加总。HS 编码和申报要素由报关人员补录、核对，未填项在草稿中列出。英文发票上的客户税则号可单独填写。

工程人员在「询价报价」的工程报价明细维护「报价采用材料」和「单件净重（kg）」。采用 AI 核价时，可带入核价材料和预计净重供工程确认。生成客户订单时系统保存成交材料。旧单缺少成交材料时，按工单加工材料、关联报价的采用材料、可识别的货品规格补齐并显示来源。全部缺失时可在出货单据补录本批材料，系统据此归类。

每箱选择货品后默认带入本批尚未装箱的数量。按件或支出货且关联报价有单件净重时，系统按实装数量估算本箱净重。拆箱时可改数量与净重，手工录入的净重在本次编辑中由用户维护，毛重和尺寸按实际装箱填写。

出货确认前，文件标记为预览。确认出货后可沿用录入资料生成新版本。取消出货的历史文件标注「已取消」。旧版单据保留原模板，可在单据历史下载。

报关资料草稿使用内置 Excel 模板，包含四张工作表及 A4 打印设置。签章区留空，明细超出单页容量时按同一版式续页。

英文商业发票和英文装箱单使用各自的模板。装箱单按箱合并箱号、尺寸和重量，货品逐项列出。公司抬头与收款说明取自本批录入的资料。

单据下载需「查看及下载出货单据」和「查询出货单」，生成还需「维护及确认出货」。正式发票登记需另授「登记正式发票」。已有租户按 [数据库维护](../../core/docs/database-workflow.md) 生成、审核及应用 MES 模型差异，再同步权限。

客户订单确认后显示「待审核」。具有「审核客户订单」（`mes:sales_order:approve`）权限的人员可从列表「操作 → 审核」进入详情，核对货品、数量、成交价和交期。审核通过后才可分批生成生产工单。修改已审核订单的成交信息会重新进入待审核；已有有效生产安排的订单仍锁定成交信息。历史已确认订单需在生成后续批次前审核。

此流程复用现有订单状态字段和操作记录。已有租户须补齐 MES 权限和字典配置。开发环境可从仓库根目录运行 `python scripts/erp.py dev sync --plugin mes --schema t_default`，将 `t_default` 换成实际租户 schema，按需给审核角色授权后重新登录。

已下单工单可在产品工单的「更多 → 工艺变更」提交变更审批，并选择已加工合格件沿用、复检或返工。正在执行的工序先结清报工并结束执行。审批通过后，沿用由有工单管理权限的人员确认，复检由质检人员录入结论，返工生成关联返修工单并在合格数量确认后生效。未报工数量按新工艺继续。报废及已登记返工数量沿原记录处置。已有正式排程批次、后序已有执行记录或有未处理的成品出货入库时，当前版本会阻止切换。迁移和配置见[工单工艺变更](database-design.md#工单工艺变更)。

询价单先由工程提交初审，初审确认价格和交期后进入待复审。复审人员可通过，或填写原因退回初审。两个环节共用报价审核权限和已有的工程自审限制，分别记录审核人、时间和版本。工作台按阶段展示待办，复审通过后才可生成客户订单。待复审导出文件标记为内部预览。已有审核通过的报价保留原状态。

拥有询价管理权限的人员可在列表或详情删除业务录入状态的询价草稿，也可填写原因作废尚未关联客户订单的已提交询价，包括审核通过的报价。作废后保留单据和审计记录，可按「已作废」筛选，本版报价不再用于生成客户订单。现有环境升级步骤见[数据库设计](database-design.md)。

订单新生成的生产工单自动带入工程已采用的报价工艺及有值的单件预估工时，复核调整后下单。工艺变更切回同一工序曾使用的工艺时，沿用设备口径相符的最近一次有效工时。委外工艺在档案确认「排程执行类别」后，排程按预计回厂时间安排。

成交折扣（最低七折）与数量档独立，订单明细保存 `discount_rate`。工程报价可参考同一客户的历史报价，符合条件时填入空白价格。

制造异常支持登记、指派、处理记录、独立复核、退回或重开及站内提醒。交付驾驶舱汇总交期风险、工序阻塞和已确认出货。

## 阅读顺序

正式方案应用后，执行与报工直接使用该批次安排的人员及设备，无需再次派工。方案详情、甘特图和报工提示显示人员姓名及设备名称。

需手动派工时，在「执行控制与派工」按姓名或工号选择工单所属组织内具备该工艺资格的生产人员。排程继续检查指定人员的资格有效期、日历和占用。未应用方案的工序保留原账号派工，重新派工后切换为生产人员。更换已应用方案安排的人员后，须重排并应用方案才能按新安排开工。无可用账号的人员由同时具备报工和生产执行管理权限的人员代录。执行记录分别保留实际人员和登录账号。升级时为目标租户生成、审核并应用 MES 迁移（新增 `mes_work_order_operation.assigned_production_person_id`）。

自动排程：生产管理新增“生产人员与技能、工作日历、排程方案”，支持资格/例外维护、计算确认、实际首件门禁、工序及委外回厂检验、剩余量重排和有条件的整单出货评估。数据库升级见[数据库维护](../../core/docs/database-workflow.md)，引擎依赖在 [scheduling-requirements.txt](scheduling-requirements.txt)。

## 当前架构的适用规则

生产领退料、手工成品入库和仓储出货通过 inv 公开服务办理。管理端支持手动报工及报工更正或冲销，变更审批复用工作流。小程序支持扫码报工与加工进度查询。
- deployment.json 明确选择插件和依赖；不使用 edu/mes/edu_mes 预置组合名。
- MES 属于 L3，依赖 inv，复用底座用户与文件能力。依赖版本以 `plugin.toml` 为准。
- plugins/mes/suite.toml 将 mes 与 inv 组合为制造套件，通用命令和页面一次处理安装/开通顺序；与教育套件共用 inv 时不会重复创建库存，停用会保留其他启用插件所需的共享依赖。
- 实际模型在 plugins/mes/backend/app/modules/mes/；新迁移在 plugins/core/backend/alembic/versions/plugins/mes/，使用 core 独立基线；旧 versions/mes 路径是历史记录。
- 源码导入、部署选择、租户迁移/启用是不同阶段；设计中的“已建表”不证明当前目标库已迁移。
- 是否已安装、启用和升级，以源码清单、正式迁移及目标租户状态为准。
- 完整 BOM/BOP/Routing 发布、质量体系、批次谱系、设备联网及库存自动记账仍属规划；工序检验与正式排程以当前实现说明及目标环境验收为准。

安装与启用见 [MES 接入](../../core/docs/mes-plugin-integration.md)。

## 文档如何随包走

发布 MES 源码包时，打包命令自动收集本目录的文档和依赖清单。

制造仓库新增“制造仓库配置”入口，原料/在制品/成品仓按用途使用，成品按工单隔离禁止混发。本项复用现有表字段，已升级 0.6 的开发库执行 `python scripts/erp.py dev sync --plugin mes --schema t_default`，重新登录后配置；历史库存不自动搬仓。

档案管理用于维护工艺、资源和生产基础资料。更新模型后，先审核并执行迁移，再同步菜单和权限。

工序检验支持合格放行、退回原工序返工和检验记录查询。

人工计划支持任务时间轴、设备看板、设备时间轴及批量调整。自动排程按加工阶段计算设备占用。

正式排程方案详情默认显示工单甘特图，时间轴定位到首段作业所在的 8 小时窗口。可切换设备或人员视图，查看整个方案，或点击条块放大到 2 小时查看分阶段安排。工单视图标出检验放行和承诺出货交期；方案窗口外的节点在总览两端显示，点击可查看实际时间。

销售管理通过「询价报价」和「客户订单」办理成交。客户订单审核后可分批生成生产工单，随后配置工序及下达；出货使用系统出货单，关联本批工单和客户订单。
