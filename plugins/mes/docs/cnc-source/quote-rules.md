# 加工报价规则维护

使用「生产管理 → 加工询价」中的报价规则维护组织的工序、材料和外协计价参数。实际费率由组织根据设备、采购条件及生产成本维护。

| 配置 | 用途 |
| --- | --- |
| 工序规则 | 从本组织已启用的正式工艺档案选择工艺，维护小时费率及参考工时 |
| 材料规则 | 维护材料牌号、别名、适用规格、密度与采购单价，核对元/kg 或元/mm 等计价单位 |
| 外协或表面处理 | 按实际采购口径维护计价单位、单价、最低收费和计费面积或重量 |
| 毛坯余量 | 按采购与装夹条件复核，区分成品净尺寸和毛坯尺寸 |

系统按已匹配的正式工艺及估算工时计算工序费用。无法覆盖的加工要求会提示待补，已识别且价格齐备的项目仍可供工程复核。更新规则后，在新的核价中采用变更，历史报价保留当时的输入与价格。

配置、权限及启用步骤见[加工询价](../cnc-quoting.md)。
