# 加工询价设计

加工询价从 STEP 三维模型和 PDF 图纸提取制造要求，结合组织工艺档案与价格规则形成由工程人员复核的报价。

1. **本地解析**：读取三维模型的尺寸、体积、表面积和几何面，解析 PDF 页面并保留文本及图纸视图。
2. **要求识别**：根据已配置的文档识别和模型服务提取材料、尺寸、公差及表面要求，保留证据与假设供人工核对。
3. **工艺匹配**：按本组织正式工艺档案拆解工序，记录工序选择、单件估时和未覆盖的加工要求。
4. **确定性计价**：使用已配置的材料、工时和外协价格计算费用，按可用信息提供参考报价并列出待补项。
5. **人工复核**：工程人员可修订材料、工艺及价格，再审核导出。报价快照保留该次输入、规则来源和结果。

几何尺寸只对应可读取的模型。仅有 PDF 或尺寸缺失时，由工程人员确认缺项；采购材料牌号、交货状态和实际加工条件也需核对。云端服务按组织配置及操作权限使用，传输资料范围见[加工询价](../cnc-quoting.md)。
